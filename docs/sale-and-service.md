# Sale and service — 2.13 ขายสินค้า, บริการ

## Scope

```text
Prototype
==========
เมนู 2.13 ใช้ชื่ออังกฤษ sale-and-service และชื่อไทย ขายสินค้า, บริการ

ข้อมูลรายชื่อสินค้า ลูกค้า และ master lookup เป็นข้อมูลสาธิตใน frontend

ใช้วันที่แบบ ISO ใน state และ input type=date
แสดงผลตาม locale ของ browser จึงอาจเห็นปี ค.ศ. หรือ พ.ศ. แตกต่างกัน
```

## Totals

```text
Calculation
==========
คำนวณเป็นหน่วยสตางค์และปัดเศษต่อรายการ
เพื่อลดผลคลาดเคลื่อนจาก floating point

Line totals
----------
ยอดรายการ       = จำนวน × ราคาต่อหน่วย − ส่วนลดรายการ
รวมมูลค่าสินค้า   = ผลรวมยอดรายการ
ยอดหลังส่วนลด    = รวมมูลค่าสินค้า − ส่วนลดท้ายบิล

Tax modes
----------
ภาษีแยกนอก: ฐานภาษี = ยอดหลังส่วนลด
             VAT = ฐานภาษี × อัตราภาษี

ภาษีรวมใน:   ฐานภาษี = ยอดหลังส่วนลด ÷ (1 + อัตราภาษี / 100)
             VAT = ยอดหลังส่วนลด − ฐานภาษี

ยกเว้นภาษี:   ฐานภาษี = ยอดหลังส่วนลด, VAT = 0

Net total
----------
มูลค่าสุทธิ = ฐานภาษี + VAT + ค่าขนส่ง

Example
----------
ตัวอย่างเริ่มต้น 20,000 − 1,000 = 19,000
VAT 7% = 1,330; สุทธิ 20,330 บาท

Prototype rules
----------
ค่าขนส่งในต้นแบบนี้เพิ่มหลังคำนวณ VAT
อัตราแลกเปลี่ยนเป็นข้อมูลประกอบ ยังไม่แปลงสกุลเงิน
ต้องกำหนดกติกาจริงร่วมกับ backend ก่อนใช้งานจริง
```

## Validation and persistence

```text
Validation
==========
ต้องมีเลขที่เอกสาร วันที่ ลูกค้า และสินค้าอย่างน้อยหนึ่งรายการ
ตรวจสอบจำนวนมากกว่า 0 ราคาและส่วนลดไม่ติดลบ ส่วนลดไม่มากกว่ายอด
อัตราภาษี 0–100% และอัตราแลกเปลี่ยนมากกว่า 0
ป้องกันเลขที่เอกสารซ้ำในข้อมูลที่จัดเก็บ

Document numbers
----------
เลขที่ DRAFT ถูกสร้างฝั่ง UI เพื่อให้แต่ละเอกสารเริ่มต้นต่างกัน
ยังไม่ใช่ระบบออกเลขเอกสารทางบัญชี

Storage limits
----------
ข้อมูลอยู่เฉพาะ browser / origin ที่บันทึก
การล้าง storage หรือเปลี่ยน browser อาจทำให้ไม่พบข้อมูล
ยังไม่มีฐานข้อมูล, การจัดการผู้ใช้ หรือการรับรองความถูกต้องทางบัญชี
backend ต้องตรวจสอบยอดและกติกาธุรกิจซ้ำเมื่อเชื่อมต่อในขั้นถัดไป
```
